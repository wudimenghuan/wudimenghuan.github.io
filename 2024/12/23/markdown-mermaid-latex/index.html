Markdown 进阶：Mermaid 图表与 LaTeX 公式

发表于 2024-12-23 更新于 2026-07-16 Disqus：

Markdown 不只能写文字。借助 Mermaid 和 LaTeX，你可以在纯文本中画流程图、写数学公式，无需任何图形工具。

Mermaid 图表

Mermaid 是一个基于 JavaScript 的图表绘制工具，用类似 Markdown 的文本语法描述图表结构，渲染成可视化图形。

流程图（flowchart）

用 flowchart TD 声明从上到下的流程图。[] 表示矩形节点，{} 表示菱形判断：

方向：TD（上→下）、LR（左→右）、RL（右→左）。

时序图（sequenceDiagram）

展示多个参与者之间的交互顺序，常用于描述 API 调用流程：

->>+ 同步调用（激活目标），-->>- 返回（关闭激活）。alt/else 条件分支，loop 循环。

LaTeX 数学公式

LaTeX 是学术排版的事实标准。在 Markdown 中用 $$ 包裹块级公式，$ 包裹行内公式。

微积分

积分：

$$
\int_a^b f(x) dx
$$

导数与偏导数：

$$
\frac{dy}{dx}, \partial
$$

矩阵

用 bmatrix 环境绘制带方括号的矩阵：

$$
\begin{bmatrix}
a & b \
c & d
\end{bmatrix}
$$

行列式

用 vmatrix 环境绘制带竖线的行列式：

$$
\begin{vmatrix}
a & b\
c & d
\end{vmatrix}
=ad-bc
$$

集合符号

$$
\infty, \cup, \cap, \in, \notin
$$

符号 含义
\infty 无穷
\cup 并集
\cap 交集
\in 属于
\notin 不属于
