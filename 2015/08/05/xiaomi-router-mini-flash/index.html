小米路由器 Mini 刷 OpenWrt

小米路由器 Mini（R1CM）是一款性价比很高的百元级路由器，MT7620A 方案，自带 128MB 内存和 16MB Flash。刷入 OpenWrt 后可以获得完整的软件包生态和更灵活的网络配置。

准备工作

  1. 下载适用于 R1CM 的 OpenWrt 固件（initramfs-kernel.bin 用于临时启动，squashfs-sysupgrade.bin 用于正式刷入）
  2. 确保电脑和路由器在同一局域网
  3. 开启路由器的 SSH（官方固件需在后台下载开发版）

刷机步骤

1. 开启 SSH 并登录

2. 进入恢复模式

断电后按住 Reset 键再通电，保持 5 秒左右，指示灯变为黄色闪烁，即进入恢复模式。此时电脑通过网线连接路由器 LAN 口，设置静态 IP 192.168.31.100。

3. 上传并刷入固件

mtd -r write 会将固件写入 firmware 分区并自动重启。

注意事项

  • 刷机前务必备份原机 art 分区（无线校准数据），丢失后 WiFi 功率和信道会异常
  • 如果刷入后无法启动，可用 Breed 不死引导恢复
  • 小米路由器 Mini 的 Flash 只有 16MB，装太多插件会空间不足，建议只装必要的

小结

小米路由器 Mini 刷 OpenWrt 的过程相对简单：开启 SSH → 上传固件 → mtd 刷入 → 重启配置。刷完后可以获得 AdGuard Home、WireGuard、SQM QoS 等完整功能，比原厂固件强大得多。
