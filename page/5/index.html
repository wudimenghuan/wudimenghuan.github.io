重装系统后 XAMPP MySQL 无法启动

重装系统后再启动 XAMPP，MySQL 服务有时报红叉或直接闪退。控制面板点 Start 没反应，日志里可能出现 InnoDB 损坏相关的错误。

问题原因

MySQL 的数据文件（ibdata1、ib_logfile 等）保存在 xampp\mysql\data 目录下。重装系统后，这些文件虽然还在，但 InnoDB 的日志序列号（LSN）和数据页状态可能与新系统环境不一致，导致启动校验失败。
