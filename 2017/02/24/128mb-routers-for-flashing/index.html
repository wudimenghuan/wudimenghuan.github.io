适合刷机的路由器推荐（128MB 起）

刷第三方固件（OpenWrt、Padavan、ImmortalWrt 等）对路由器硬件有一定要求：内存至少 64MB，128MB 更为充裕；闪存 16MB 才能装下完整的固件和插件。下面整理的所有机型，均可在 OpenWrt 官方 Table of Hardware 找到对应页面，或有官方/社区公开镜像可刷。

如何验证一台路由器能刷 OpenWrt

每台可刷机器在 OpenWrt 官方 ToH 都对应一个页面，例如：

  • https://openwrt.org/toh/xiaomi/redmi_ax6s
  • https://openwrt.org/toh/xiaomi/redmi_ax6000
  • https://openwrt.org/toh/qihoo/360t7_1.0

官方页面会标注支持版本（如 22.03 / 23.05 / 24.10）和刷入方式。遇到不在 ToH 的型号，建议先查 OpenWrt forum 是否有现成教程，否则不要轻易尝试。

选购建议

预算 推荐 用途
< 100 元（学习/折腾） 优酷路由宝、newifi mini、二手 K2P 学习刷机，跑满普通宽带
100-300 元 红米 AX6S、360T7（需要拆机）+ 红米 AX6000 千兆+宽带、WiFi 6、日常使用
> 300 元 GL.iNet AXT1800 出厂 OpenWrt，可直接装插件
软路由方案 斐讯 N1 + 单独 AP 性价比极致，2W 低功耗

刷机要点提醒

  1. 不死引导 (Breed)：建议先刷 Breed，之后可以随意刷不同固件而不怕变砖（仅适合 MT7620/MT7621/部分 MT7981）
  2. 闪存分区：16MB Flash 装 OpenWrt 后剩余空间约 8-10MB，装 1-2 个插件刚好够用；要更多插件考虑 32MB+ 闪存机型
  3. OpenWrt 版本：当前 OpenWrt 23.05 / 24.10 是主版本号，22.03 是 LTS，老旧机器可能要选 19.07
  4. 厂商防刷：360T7 等机型厂商已发新版锁机，关注 OpenWrt forum / 恩山论坛 最新解锁工具

小结

入门首选：红米 AX6S（OpenWrt 官方直支持，工厂镜像直接刷）。预算充足选：红米 AX6000（MT7986A 四核 + 2.5G）或 GL.iNet AXT1800（出厂 OpenWrt，省事）。斐讯 N1 50 元级做软路由无敌。

本文中所有列出的路由器型号都已通过 OpenWrt 官方 ToH 或社区 GitHub 仓库验证。不在 ToH 但民间能刷的机型（如部分运营商定制机）请根据相关社区教程自行评估风险。
