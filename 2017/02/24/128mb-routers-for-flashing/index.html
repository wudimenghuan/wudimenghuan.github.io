适合刷机的 128MB 内存路由器推荐

刷第三方固件（如 OpenWrt、Padavan、老毛子）对路由器硬件有一定要求：内存至少 64MB，128MB 更为充裕；闪存 16MB 才能装下完整的固件和插件。下面整理了一批性价比高、社区支持好的百元级刷机路由器。

128MB 内存机型

型号 配置 特点
优酷路由宝 MT7620A, 16M Flash, 128M RAM, 2.4G 自带 USB + SD 卡槽，挖矿时代产物，刷机性价比极高
极路由-极贰 HC5761 MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 双频 + USB + SD，社区固件成熟
极路由-极叁 HC5861 MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 极贰升级版，LAN 口带一个千兆
水牛 1166DHP MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 日本品牌，国内刷机圈有一定保有量
联想 newifi mini (Y1) MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 刷机最友好的机型之一，固件资源丰富
小米路由器 Mini MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 小米早期良心产品，MT7620A 方案稳定

256MB 内存机型（进阶选择）

型号 配置 特点
联想 newifi (Y1S) MT7620A, 16M Flash, 256M RAM, 2.4/5G 双频 3 个 USB + 千兆 WAN/LAN，内存翻倍装插件更宽裕
联想 newifi2 (D1) MT7621A, 32M Flash, 256M RAM, 2.4/5G 双频 双核 + 32M 闪存 + USB2.0 + SD 卡，可玩性最高
优酷路由宝 L2 MT7620A, 16M Flash, 256M RAM, 2.4/5G 双频 USB3.0 + SD 卡，L1 的内存升级版

刷机要点

  1. 复位键 GPIO：每款机型的复位键对应不同的 GPIO 编号，刷 Breed 不死引导时需要正确填写，否则无法进入恢复模式
  2. ** breed 不死引导**：建议先刷 Breed，之后可以随意刷不同固件而不怕变砖
  3. 闪存分区：16MB Flash 刷 OpenWrt 后可用空间约 8-10MB，装 AdGuard Home、WireGuard 等插件刚好够用；如果需要更多空间考虑 32MB Flash 机型
  4. MT7620A vs MT7621A：MT7620A 单核 580MHz，MT7621A 双核 880MHz，后者 NAT 性能和 USB 读写速度明显更强

小结

对于入门刷机，推荐 小米路由器 Mini 或 联想 newifi mini，社区资料最全、固件最多。如果预算稍高，联想 newifi2 (D1) 的 256MB 内存 + 32MB 闪存 + 双核配置可以当作小型 NAS 或软路由使用，性价比极高。
