适合刷机的路由器推荐（128MB 起）

刷第三方固件（如 OpenWrt、Padavan、老毛子）对路由器硬件有一定要求：内存至少 64MB，128MB 更为充裕；闪存 16MB 才能装下完整的固件和插件。下面整理了一批从入门到旗舰的刷机路由器，覆盖近十年市场主流型号。

极路由-极贰 HC5761 MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 双频 + USB + SD，社区固件成熟
极路由-极叁 HC5861 MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 极贰升级版，LAN 口带一个千兆
水牛 1166DHP MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 日本品牌，国内刷机圈有一定保有量

小米路由器 Mini MT7620A, 16M Flash, 128M RAM, 2.4/5G 双频 小米早期良心产品，MT7620A 方案稳定

选购建议

预算 推荐 用途
< 50 元（折腾向） 优酷路由宝、newifi mini、二手 K2P 学习刷机，跑满普通宽带
50-150 元 红米 AX6S、360T7、小米 WR30U 千兆宽带、WiFi 6、日常使用
150-300 元 红米 AX6000、GL.iNet AXT1800 2.5G 宽带，多设备并发
> 300 元 友善 R4S + 单独 AP 软路由搭配方案

刷机要点提醒

  1. 复位键 GPIO：每款机型的复位键对应不同的 GPIO 编号，刷 Breed 不死引导时需要正确填写
  2. 不死引导 (Breed)：建议先刷 Breed，之后可以随意刷不同固件而不怕变砖
  3. 闪存分区：16MB Flash 装 OpenWrt 后剩余空间约 8-10MB，装 1-2 个插件刚好够用；要更多插件考虑 32MB+ 闪存机型
  4. 运营商机解绑：运营商定制机先解绑网络锁定（TTL 改写或解封装），否则 LAN 口可能被封
  5. 官方防刷：360T7、CR660x 等机型厂家已推防刷策略，关注 GitHub 社区的最新解锁工具

小结

入门首选：360T7 或 红米 AX6S（百元价格，千兆+WiFi 6，社区活跃）。预算充足选：红米 AX6000 或 GL.iNet AXT1800（带不死引导、出厂 OpenWrt）。纯软路由玩家：斐讯 N1（50 元级）、友善 R4S（2.5G）。
