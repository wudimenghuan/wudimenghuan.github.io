小米路由器更改区域代码解锁隐藏信道

小米路由器（AX1800/AX5/AX6/AX6S 等）的国行版本默认地区为 CN，无线信道选项极少。通过解锁 SSH 并修改国家/地区代码，可以开启更多 5G DFS 信道和 160MHz 带宽，显著提升无线性能。

第一步：解锁 SSH

使用开源工具 xmir-patcher 解锁 SSH 权限：

  • 仓库地址：https://github.com/openwrt-xiaomi/xmir-patcher
  • 按 README 步骤运行，登录小米账号获取 token
  • 工具会自动注入 SSH 公钥

成功后可以用 ssh root@192.168.31.1 登录路由器（默认无密码或密码与后台相同）。

第二步：查看当前区域

默认输出 CN，代表中国大陆。

第三步：修改为 EU 等其他区域

可选代码：EU、HK、TW、KR、CN。EU 最为通用，可解锁最多信道。

选 US 可以解锁 5GHz 的 UNII-1/2/3 全频段（含 DFS），包括 149-165 这些高信道。

第四步：同步 UCI 无线配置

仅修改 CountryCode 还不够，需要同步修改 wireless 配置：

AX6 系列（wifi0/wifi1）

AX6S（MT7622/MT7915）

第五步：应用配置

生效后后台的「无线信道」选项会大幅增加，特别是 5GHz 信道从国行的 5 个左右扩展到 20+ 个。

注意事项

  1. 合规风险：在非居住国使用无线频率可能违反当地法规（例如美国 FCC、欧盟 CE 要求路由器声明销售区域）
  2. 信道不合法：DFS 信道（52-144）如有雷达会触发自动切换，可能短暂断连
  3. 160MHz 带宽：开启 160MHz 会占用更多连续信道，只有少数信道（如 UNII-8 的 149-165 + 5 组相邻）支持
  4. 刷机风险：解锁 SSH 和改 nvram 不会失去保修（基于公开 CVE），但升级固件可能被官方修复堵上

小结

通过一行 nvram set CountryCode=US + 同步 UCI 配置，就能把小米路由器的无线性能从国行受限版本解锁到接近海外版。这是从 UCD-Linux 衍生社区最常用的”硬核玩法”，但务必确认当地法规允许后再使用。
